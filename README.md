# RigFlowOS V1.2 — NERD UPDATE

RigFlowOS est un environnement logiciel expérimental développé pour **BBC micro:bit V2**.

Le projet cherche à pousser au maximum les capacités du micro:bit grâce à une interface personnalisée, un écran OLED et différents périphériques externes.

## 📟 Version micro:bit

La version actuelle de RFOS fonctionne directement sur **micro:bit V2**.

Elle permet notamment d'utiliser :

- OLED 128×64
- Joystick
- Boutons
- Matrice de boutons
- GPIO
- Système de scènes
- Settings
- Gestion du son
- Modes de vitesse

## 🖥️ RigFlowOS Desktop

> 🟠 **EN COURS DE DÉVELOPPEMENT**

RigFlowOS Desktop est la future branche PC de l'écosystème RigFlow.

Le projet Desktop est actuellement en développement et **ne constitue pas encore une version finale ou stable**.

L'objectif est notamment de permettre à terme la communication entre le PC, RFOS et les différents outils RigFlow.
