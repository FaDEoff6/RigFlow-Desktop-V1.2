# RigFlow-Desktop-V1.2
🖥️ RigFlowOS &amp; RigFlowOS Desktop  RigFlowOS (RFOS) est un environnement logiciel expérimental développé autour du concept de transformer un matériel simple en véritable plateforme interactive. Né sur micro, RFOS exploite au maximum les ressources disponibles pour proposer une interface, des menus, des paramètres et différents outils accessibles.
